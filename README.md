## 🌟 Overview

QR Studio is a sophisticated, production-grade application designed for crafting gorgeous, highly-customized QR codes entirely within the browser. Featuring glassmorphism aesthetics, live-updating previews, and extensive styling controls, it bridges the gap between utility and design. No backends, no API delays—just lightning-fast, client-side generation.

---

## ✨ Features

- **Dynamic Data Types:** Generate codes for URLs, Plain Text, Emails, Phone Numbers, and fully-configured Wi-Fi networks.
- **Real-Time Live Preview:** Watch your QR code transform instantly as you tweak settings.
- **Deep Customization:** Complete control over foreground/background colors (including linear gradients!), custom pattern styles (Dots, Rounded, Classy), and error correction levels.
- **Embedded Logos:** Easily drop a URL to center a logo perfectly inside the code with automatic error-correction recommendations.
- **Smart Validation:** Integrated contrast checker prevents the creation of unscannable QR codes, while smart input validation ensures data accuracy.
- **Local History:** Your recent masterpieces are automatically saved to local storage for quick retrieval.
- **Flawless Exports:** Copy directly to your clipboard or download pixel-perfect PNG and SVG files.
- **Premium UI/UX:** Built with a stunning dark/light mode toggle, subtle mesh gradients, glass panels, and smooth micro-interactions.

## 🚀 Tech Stack

- **Frontend Framework:** React 18
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **QR Core Library:** qr-code-styling

## 🛠️ Local Setup & Installation

Get up and running on your local machine in seconds.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/QR-studio.git
   cd QR-studio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
